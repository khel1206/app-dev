# John Wick

## Overview

*John Wick* is a **neo-noir action thriller** released in 2014. It stars Keanu Reeves as a retired hitman who returns to the criminal underworld for revenge.

![John Wick movie poster](https://static.wikia.nocookie.net/john-wick8561/images/d/d5/JW1_final_poster_release.jpg/revision/latest/scale-to-width-down/1200?cb=20231215021818)

> A simple revenge story turned into a stylish and unforgettable action movie.
